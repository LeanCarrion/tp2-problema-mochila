# TP N°2: El Problema de la Mochila (Knapsack Problem)

Este proyecto implementa y compara dos enfoques algorítmicos clásicos para resolver el **Problema de la Mochila 0-1**, desarrollado como parte de la materia Algoritmos Genéticos.

## 📋 Características del Proyecto
El programa está desarrollado en **Python** y cuenta con un menú interactivo en consola para ejecutar las siguientes opciones:
1. **Mostrar objetos:** Visualiza la lista de elementos disponibles con sus respectivos volúmenes y valores.
2. **Búsqueda Exhaustiva:** Encuentra la solución óptima absoluta evaluando todas las combinaciones posibles mediante fuerza bruta.
3. **Algoritmo Greedy (Goloso):** Resuelve el problema de manera rápida utilizando tres criterios de ordenamiento seleccionables (Mejor Valor, Mejor Volumen o Mejor Relación Valor/Volumen).
4. **Comparar métodos:** Ejecuta ambos algoritmos en paralelo utilizando una instancia basada en pesos (gramos) para analizar y contrastar el grado de optimización de cada enfoque.

## 🚀 Cómo ejecutarlo
1. Asegúrate de tener instalado Python en tu computadora.
2. Abre la terminal en la carpeta del proyecto.
3. Ejecuta el siguiente comando:
   ```bash
   python TpN°2.py
   ```
